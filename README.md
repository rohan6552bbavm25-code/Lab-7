This project focuses on **professional aviation email writing using Generative AI**. The main objective is to learn how structured prompts can help create clear, accurate and professional workplace communication while ensuring that the final message is reviewed by a human before business use.

The activity introduces a **six-part structured prompt** consisting of Role, Task, Context, Constraints, Output Format and Tone. Students first test a weak prompt about a delayed flight and identify the information missing from it. They then create a structured prompt using the verified details of Flight AV408 from Delhi to Bengaluru, including its two-hour weather-related delay and revised departure time of 5:00 PM.

The project also introduces two communication frameworks: **BLUF (Bottom Line Up Front)** for urgent operational communication and **PAS (Problem, Agitation, Solution)** for persuasive communication. Students learn that BLUF is useful for flight delays, cancellations, gate changes and operational updates, while PAS should be used carefully without exaggerating passenger concerns.

A major part of the lab is the **four-dimension review gate**, which evaluates AI-generated emails based on Accuracy, Tone, Compliance and Context. Students identify unsupported claims, revise the email using targeted follow-up prompts and create a final version suitable for human review.

The project further includes writing a passenger-complaint response, an internal airport staff email and different versions of the same message for passengers, senior management and operations staff. Peer review is also used to improve the final drafts.

Finally, students complete reflection questions and save the activity as `workplace-writing-professional-email.md` for upload to their `genai-business-portfolio` GitHub repository.
